# Portfolio

Next.js 16 + Tailwind CSS v4. Fully static, no client JS needed.

## Run locally
    npm install
    npm run dev   # http://localhost:3000

## Edit content
All text lives in `lib/data.ts`. Search for `TODO` and fill in:
- email, GitHub, LinkedIn URLs
- TradieHub repo link + live URL (the "Live site" button appears once `live` is set)
- Outback Yak / Evalue8 titles, dates and bullet points
- Drop your resume at `public/resume.pdf`

## Deploy
Push to GitHub → import the repo at vercel.com → Deploy. Add a custom domain in Project → Settings → Domains.
